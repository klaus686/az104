## 🚀 Project Overview

Welcome to my **Microsoft Azure Administrator (AZ-104) Hands-On Portfolio Project**.

This repository documents my practical learning journey in Microsoft Azure, covering cloud infrastructure deployment, configuration, administration, networking, security, monitoring, and troubleshooting.

The objective is to gain real-world experience by implementing Azure services through the Azure Portal, understanding their configurations, capturing practical implementation screenshots, and documenting each step.

This project follows the core learning objectives of the Microsoft AZ-104 Azure Administrator certification.

## 🎯 Project Objectives

- Gain practical experience with Microsoft Azure services.
- Understand Azure infrastructure and resource management.
- Implement cloud networking and security configurations.
- Deploy and manage Azure compute resources.
- Configure identity and access management.
- Implement Azure storage solutions.
- Monitor and troubleshoot Azure resources.
- Understand resource optimization and cost management.
- Build a practical cloud administration portfolio for career development.

## 🏗️ Practical Implementation

This portfolio focuses on implementing Azure infrastructure using practical scenarios.

### 1. Identity & Governance
- Manage Azure identities and access.
- Configure role-based access control (RBAC).
- Understand resource groups and subscriptions.
- Explore Azure Policy and resource governance.

### 2. Storage
- Create and configure storage accounts.
- Explore blob containers and storage access.
- Understand storage redundancy and access tiers.
- Configure secure storage connectivity.

### 3. Compute
- Create and configure Azure App Service.
- Deploy a web application using GitHub Actions.
- Configure application settings and environment variables.
- Explore deployment and application monitoring.
- Practice Azure Virtual Machine administration.

### 4. Networking
- Create Virtual Networks and subnets.
- Configure Network Security Groups.
- Establish VNet peering.
- Configure private endpoints.
- Explore Private DNS Zones and DNS resolution.

### 5. Monitor & Maintain
- Explore Azure Monitor.
- Configure metrics and monitoring.
- Analyze application and resource logs.
- Understand alerts, backup, and recovery options.

## 💰 Cost Management Strategy

Cost optimization is an important part of this project.

The labs prioritize Azure free-tier services and available subscription credits wherever possible.

My cost management approach includes:

- Prefer free or low-cost Azure resources.
- Monitor resource usage and estimated costs.
- Avoid unnecessary paid resources.
- Delete temporary lab resources after documenting them.
- Keep essential resources only when appropriate.
- Document resource costs and cleanup activities.

**Note:** Azure services may incur charges depending on subscription type, region, usage, and configuration. Always verify pricing before deployment.

## 📖 Learning Approach

Every module follows a practical learning approach:

1. Understand the Azure service and its purpose.
2. Create resources through the Azure Portal.
3. Configure the required settings.
4. Validate the deployment.
5. Capture implementation screenshots.
6. Document the configuration and results.
7. Troubleshoot issues encountered during implementation.
8. Clean up temporary resources where appropriate.
